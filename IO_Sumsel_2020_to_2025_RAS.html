Proyeksi Tabel I-O Sumatera Selatan 2020 ke 2025 dengan Metode RAS

Proyeksi Tabel I-O

Dokumen ini memproyeksikan Tabel Input-Output (I-O) Provinsi Sumatera Selatan dari tahun dasar 2020 ke tahun target 2025 menggunakan metode pemutakhiran temporal RAS (biproportional matrix balancing). Informasi tahun target diambil dari PDRB Atas Dasar Harga Konstan (ADHK) 2010 menurut lapangan usaha. Prosedur terbagi dalam 7 section utama.

Catatan dasar harga: Tabel I-O 2020 disusun atas dasar harga berlaku (ADHB) 2020, sedangkan PDRB disajikan atas dasar harga konstan 2010. Informasi yang diambil dari PDRB hanya indeks pertumbuhan riil (rasio 2025/2020), sehingga tabel hasil proyeksi adalah Tabel I-O 2025 atas dasar harga konstan 2020. Tabel ini mencerminkan perubahan volume dan struktur riil perekonomian, bukan nilai nominal 2025.

1 Pembacaan dan Persiapan Data

Ada empat hal utama yang dilakukan pada Section 1:

  1. Struktur Berkas: berkas io_sumsel_2020.csv merupakan ekspor apa adanya dari sheet “I-O Sumsel 2020” (pemisah koma, desimal titik). Dua baris teratas (judul tabel dan baris kosong) dilewati, sehingga baris header berisi kode kolom I-O (1–54, 180, 301–305, 309, 310, 409, 509, 600, 700).

  2. Standardisasi Dimensi: nama baris diseragamkan menggunakan kolom “Kode I-O”, sedangkan nama kolom menggunakan kode pada header. Kolom deskripsi dan kolom tanpa kode numerik (sel catatan di luar tabel) dikeluarkan dari struktur data sebelum operasi aljabar dilakukan.

  3. Tanda pemisah ribuan koma (,) dihilangkan dan sel kosong (NA) diubah menjadi 0 agar data yang dihasilkan berupa numerik murni.

  4. Berkas PDRB: kode lapangan usaha (misal A.1.c, C.2, M,N) diekstraksi dari awal teks label, dan kolom tahun dideteksi otomatis. Dengan demikian skrip tetap berjalan bila data diperluas, misalnya menjadi 2014–2025.

2 Standarisasi Data

Tabel I-O BPS mengikuti konvensi kode baris dan kolom yang baku:

  • Baris 1–54 dan kolom 1–54 (Sektor): sektor produksi domestik. Kode ini muncul sekaligus pada baris dan kolom, sehingga dapat diidentifikasi sebagai irisan kode baris dan kode kolom.

  • Baris 190, 200 (Input Antara): total input antara domestik dan input antara impor.

  • Baris 201–204 (Nilai Tambah Bruto): 201 kompensasi tenaga kerja, 202 surplus usaha bruto (termasuk pendapatan campuran), 203 pajak lainnya atas produksi, 204 subsidi lainnya atas produksi. Baris 209 adalah total NTB dan 210 total input.

  • Kolom 180, 301–305, 309, 600 (Permintaan): 180 total permintaan antara; 301 konsumsi rumah tangga (termasuk LNPRT), 302 konsumsi pemerintah, 303 PMTB, 304 perubahan inventori, 305 ekspor; 309 total permintaan akhir; 600 total output.

Kolom 304 (perubahan inventori) adalah satu-satunya kolom yang memuat nilai negatif. Karena algoritma RAS hanya terdefinisi untuk matriks non-negatif, kolom ini diperlakukan sebagai eksogen (tidak ikut diseimbangkan).

Pencocokan awalan kode (startsWith) digunakan agar skrip tetap konsisten bila struktur kolom permintaan akhir berbeda pada rilis tabel yang lain. Syarat panjang kode tiga digit (nchar == 3) ditambahkan agar kode sektor seperti 20 dan 30 tidak ikut terpilih sebagai akun NTB atau permintaan akhir.

Konkordansi Sektor: PDRB menyajikan 52 lapangan usaha, sedangkan Tabel I-O memuat 54 sektor. Selisih dua sektor berasal dari rincian subsektor perkebunan: sektor I-O 3 (Karet), 4 (Kelapa Sawit), dan 5 (Tanaman Perkebunan Lainnya) seluruhnya dipetakan ke A.1.c Tanaman Perkebunan, sehingga ketiganya menggunakan indeks pertumbuhan yang sama. Sebanyak 51 sektor lainnya berpasangan satu-satu.

3 Ekstraksi Blok I-O 2020 dan Koefisien Teknis

Seluruh blok tabel dasar 2020 diekstraksi dari io_mat:

  • Matriks Transaksi Antara Domestik (\(Z_0\)): transaksi barang dan jasa domestik sektor \(i\) yang digunakan sebagai input antara oleh sektor \(j\).

  • Vektor Output (\(X_0\)), Input Antara Impor (\(M_0\)), Nilai Tambah Bruto (\(VA_0\), penjumlahan baris 201–204), serta Permintaan Akhir domestik (\(F_0\)).

  • Verifikasi Keseimbangan Tahun Dasar: pada setiap sektor harus berlaku \[X_j = \sum_i z_{ij} + M_j + VA_j \quad \text{(sisi input)}, \qquad X_i = \sum_j z_{ij} + \sum_k f_{ik} \quad \text{(sisi output)}\]

Matriks Koefisien Teknis tahun dasar menjadi titik awal (prior) algoritma RAS: \[A_0 = Z_0 \hat{X}_0^{-1}, \quad \text{dengan } a_{ij} = \frac{z_{ij}}{X_j}\]

Selain itu dihitung rasio input primer per sektor, yaitu rasio NTB \(\rho_j = VA_j / X_j\) dan rasio impor antara \(\mu_j = M_j / X_j\). Sektor dengan output nol (Pertambangan Bijih Logam) diberi koefisien nol untuk menghindari pembagian dengan nol.

# Extract 2020 Blocks

4 Target Marjin 2025 dari PDRB ADHK

Indeks pertumbuhan riil setiap sektor dihitung dari PDRB ADHK: \[g_j = \frac{PDRB_{j,2025}}{PDRB_{j,2020}}\]

Karena tahun target 2025 tersedia langsung pada data PDRB, rasio output terhadap NTB tidak perlu diestimasi dari tren historis. Rasio tahun dasar dipertahankan (asumsi teknologi input primer tetap), sehingga marjin 2025 diturunkan sebagai berikut:

  • Nilai Tambah: \(VA_{j,2025} = g_j \, VA_{j,2020}\). Komponen NTB (201–204) bergerak proporsional mengikuti pangsa 2020.

  • Output: \(X_{j,2025} = VA_{j,2025} / \rho_j\).

  • Impor Antara: \(M_{j,2025} = \mu_j \, X_{j,2025}\).

  • Target Kolom Input Antara Domestik: \(v_j = X_{j,2025} - VA_{j,2025} - M_{j,2025}\).

  • Target Baris: \(u_i = X_{i,2025} - INV_{i,2025}\), dengan perubahan inventori \(INV_{i,2025} = g_i \, INV_{i,2020}\) (eksogen).

  • Target Kolom Permintaan Akhir (\(f_k\)): baris permintaan akhir 2020 diskalakan dengan \(g_i\), lalu disesuaikan dengan skalar penutup \(\lambda\) agar total target baris sama dengan total target kolom (syarat keberadaan solusi RAS): \[\lambda = \frac{\sum_i u_i - \sum_j v_j}{\sum_i \sum_k g_i \, F_{ik,2020}}, \qquad f_k = \lambda \sum_i g_i \, F_{ik,2020}\]

Permintaan akhir ikut diseimbangkan di dalam RAS, bukan ditetapkan sebagai residual tetap. Sebagian sektor (misalnya Administrasi Pemerintahan) hampir tidak memiliki penjualan antara. Jika permintaan akhirnya dipatok di luar RAS, target baris \(Z\) untuk sektor tersebut menjadi tidak konsisten dan algoritma tidak dapat konvergen.

Laju pertumbuhan tahunan rata-rata (CAGR) \(\left(g_j^{1/(2025-2020)} - 1\right)\) juga dihitung sebagai informasi pendukung.

5 Algoritma RAS

Metode RAS (Stone, 1961; Bacharach, 1970; Miller & Blair, 2009, Bab 7) mencari matriks baru yang sedekat mungkin dengan struktur tahun dasar namun memenuhi marjin baris dan kolom tahun target. Matriks yang diseimbangkan adalah matriks gabungan \(T = [\,Z \mid F\,]\) (transaksi antara dan permintaan akhir non-inventori).

  • Prior: koefisien teknis 2020 diterapkan pada output 2025, dan permintaan akhir 2020 diskalakan dengan pertumbuhan sektor: \[T^{(0)} = \left[\, A_0 \hat{X}_{2025} \;\middle|\; \hat{g} F^{*}_{2020} \,\right]\]

  • Langkah R (penyesuaian baris): \[r_i = \frac{u_i}{\sum_j t_{ij}}, \qquad T \leftarrow \hat{r} \, T\]

  • Langkah S (penyesuaian kolom): \[s_j = \frac{[v, f]_j}{\sum_i t_{ij}}, \qquad T \leftarrow T \, \hat{s}\]

  • Kriteria Konvergensi: iterasi dihentikan bila \[\max\left( \left|T\mathbf{1} - u\right|, \; \left|\mathbf{1}^\top T - [v, f]\right| \right) < \varepsilon\]

Hasil akhir setara dengan \(Z_{2025} = \hat{R} \, A_0 \hat{X}_{2025} \, \hat{S}\), sehingga koefisien teknis 2025 adalah \(A_{2025} = \hat{R} A_0 \hat{S}_Z\). Efek substitusi ditangkap oleh \(\hat{R}\) (baris), sedangkan efek fabrikasi ditangkap oleh \(\hat{S}\) (kolom). Baris atau kolom dengan jumlah nol (sektor Bijih Logam) diberi faktor 1 sehingga tetap bernilai nol.

# --- Build Prior Matrix ---
T_prior <- cbind(A_0 %*% diag(X_1), FD_prior)
rownames(T_prior) <- sec_codes
colnames(T_prior) <- c(sec_codes, fd_ras_codes)

u_target <- row_target
v_target <- c(col_target_Z, col_target_FD)

# Feasibility: positive target requires a non-zero prior row/column
stopifnot(all(u_target[rowSums(T_prior) == 0] == 0))
stopifnot(all(v_target[colSums(T_prior) == 0] == 0))

# --- RAS Iteration ---
tol      <- 1e-6      # Juta Rupiah
max_iter <- 10000
iter     <- 0
gap      <- Inf
T_ras    <- T_prior

while (gap > tol && iter < max_iter) {
  iter <- iter + 1

  # R step: row scaling
  row_sum <- rowSums(T_ras)
  r_fac   <- ifelse(row_sum > 0, u_target / row_sum, 1)
  T_ras   <- diag(r_fac) %*% T_ras

  # S step: column scaling
  col_sum <- colSums(T_ras)
  s_fac   <- ifelse(col_sum > 0, v_target / col_sum, 1)
  T_ras   <- T_ras %*% diag(s_fac)

  gap <- max(abs(rowSums(T_ras) - u_target), abs(colSums(T_ras) - v_target))
}

rownames(T_ras) <- sec_codes
colnames(T_ras) <- c(sec_codes, fd_ras_codes)

if (gap > tol) warning("RAS did not converge within max_iter")
cat("RAS iterations:", iter, "| max margin gap:", format(gap, scientific = TRUE), "\n")

6 Konstruksi Tabel I-O 2025 dan Verifikasi Keseimbangan

  • Matriks Transaksi Antara (\(Z_{2025}\)) dan Permintaan Akhir (\(F_{2025}\)): diperoleh langsung dari hasil RAS, ditambah kolom perubahan inventori eksogen.

  • Blok Input Primer: input antara impor \(M_{2025}\) dan komponen NTB 201–204 dari Section 4.

  • Verifikasi Keseimbangan Akuntansi (Row-Column Balancing): memastikan bahwa pada setiap sektor berlaku \[\text{Total Input}_j = \sum_i z_{ij} + M_j + VA_j \; = \; \sum_j z_{ij} + \sum_k f_{ik} = \text{Total Output}_j\]

  • Matriks Koefisien Teknis \(A_{2025} = Z_{2025}\hat{X}_{2025}^{-1}\) dan Pengganda Leontief \(L_{2025} = (I - A_{2025})^{-1}\).

Susunan tabel dipertahankan sama dengan tabel asli BPS: 54 sektor, kolom 1–54, 180, 301–305, 309, 310, 409, 509, 600, 700 serta baris 1–54, 190, 200, 201–204, 209, 210. Kolom 310 adalah total permintaan, 409 total impor (hanya terisi pada baris 200), 509 margin (nol pada tabel transaksi domestik atas dasar harga produsen), dan 700 total penyediaan.
